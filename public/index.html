How delivery works

  • SMTP Real email is sent using the SMTP_* environment variables.
  • Preview No SMTP configured — a preview inbox (Ethereal) is used; sends return a preview link.
  • Log only No network for the preview service; messages are logged only.

Set your provider's SMTP details as environment variables (host, port, user, pass), then restart. On Railway, use port 2525 — ports 25/465/587 are blocked.
