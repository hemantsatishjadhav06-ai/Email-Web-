Settings & delivery

How delivery works

  • SMTP — real email is sent using the SMTP_* values in your .env.
  • Ethereal — no SMTP configured, so a preview inbox is used. Sent messages return a preview link (nothing reaches real inboxes).
  • Stub — no network for the preview service; messages are logged only.

Copy .env.example to .env and add your provider's SMTP details, then restart.
